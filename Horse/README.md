# 雙人馬 0.5.0

原創低多邊形馬取代小車，血量、YouTube 和馬共用 `TONY_BIG_SET.dll`。
F6 免費生成及自動生成車輛已移除。

## 模型與動畫

- 13 個關節、70 個專用 mesh 部件、7,752 三角面；栗色馬身、分束棕色鬃毛與尾巴、雙人皮鞍及中空馬鐙。
- 待機時頭、耳朵與尾巴輕微活動；移動速度驅動四肢，逐漸由行走過渡到奔跑。
- `Assets/model.json` 是 DLL 和 `Assets/preview.html` 共用的模型資料；預覽可直接用瀏覽器打開，不連外。
- 全部模型及程序動畫是本專案原創，沒有第三方模型或付費資源，也不需 Unity Editor / Blender 安裝。
- 角色為 Humanoid Animator 時套用雙腿騎乘姿勢，下馬或離線後恢復；非 Humanoid 模型不強制改骨架。
- 這是風格化程序動畫，沒有地形蹄部 IK、馬叫聲、獨立馬匹 AI 或寫實骨骼蒙皮。

## 購買與操作

1. 房主和所有騎乘者安裝同版本 DLL，重啟遊戲。
2. 商人的一般商品頁購買「雙人馬」，預設 **1 金幣**，由原生購買流程扣款。
3. 在戶外開啟背包，使用「雙人馬」物品，會嘗試在玩家前方約 3.5 公尺放置。
4. 位置須有地面支撐、沒有屋頂與障礙。生成成功後才消耗物品，失敗保留物品。
5. 靠近按 **E** 上馬，第一個空位先分配駕駛；最多兩人。
6. 駕駛 **WASD** 移動、**Shift** 加速；**E** 尋找安全位置下馬。
7. **Ctrl+1** 切換到空的駕駛位；**Ctrl+2**（牛馬2 為 Ctrl+2～5）切換到空的乘客位；不會換掉手上的裝備。
8. 無人騎乘時，準星對準馬身（2 公尺內）會出現原生提示「[X] - 收回背包」；長按 **X**（遊戲的移除鍵，手把 Y）約 1 秒，馬變回背包物品，可再放置。

目標已有乘員就拒絕換位，不強制交換。駕駛改到後座後馬停止，乘客不會自動成為駕駛。
可購買多匹，每匹各自有兩個座位；每個存檔最多同時放置 32 匹。
收回由房主驗證：需無人騎乘、玩家在馬身 3 公尺內；房主開啟「禁止客人移除家具」時只有房主能收。背包滿時拒絕並保留馬匹，不會把物品掉在地上。
本版透過背包的「使用」放置，沒有滑鼠放置預覽或快捷列放置工具。

## 設定

同一個 `BepInEx/config/Tony.TeammateHealthBars.cfg`：

- `[Horse] Price = 1`：商品價格，調整後重啟。
- `[Horse] Enabled = true`、`MountKey = E`。
- 保留原本 `[Cart] SpeedMultiplier = 1.8`、`SprintMultiplier = 2.4`，讓舊速度設定延續使用。
- 舊 `[Cart] SummonKey` 已沒有作用。

商品使用 ID **47920**，註冊時檢查重複 ID；碰到其他模組占用則停用該商品並記錄錯誤。
主機負責商品扣除、放置驗證、座位分配；駕駛仍沿用原生 owner movement。
騎乘中的馬每秒同步約 10 次，空馬每秒 1 次，中途加入會收到馬匹清單與座位。

## 存檔

跟隨原生「存檔成功」事件，將每匹馬的 ID、場景、位置與方向存到
`BepInEx/config/Tony.Horses/<原生存檔快照 SHA256>.json`。
座位不存入檔案，重新讀檔後都是空馬。

不改寫原生存檔格式。附加檔依完整 SaveData 快照識別，載入備份時只讀對應快照的馬匹。
請在備份／搬移遊戲存檔時一併保留整個 `Tony.Horses` 資料夾；只有原生存檔而沒有附加檔時不會還原馬。
附加檔保留舊快照，沒有自動刪除，因此長期遊玩會累積小型 JSON 檔。
讀取損毀檔案會記錄錯誤，不刪除原檔。馬和背包物品的耐久性以遊戲正常存檔為準，異常終止前未保存的變更不保證保留。

最新外觀更新的驗證、離線渲染與限制見 [model-validation.md](model-validation.md)。

## 驗證狀態

已通過編譯；首次 17 項 URL 測試與 17302 項座位／步態 assertions 通過。
模型結構、兩個鞍座、預覽與打包資料一致性，以及 Harmony API 目標另外做靜態檢查。
之後再次執行 URL 測試時 Windows Application Control 阻擋了新編譯的 `UrlTests.exe`；沒有關閉安全防護。

**尚未做遊戲內或雙人連線驗證。** 必測項目：

- 商店名稱、圖示、價格；金額不足與背包滿載購買。
- 屋內／斜坡／障礙／水邊放置失敗不消耗物品；連續使用不重複生成。
- 兩人同時上馬、換位競爭、坐滿拒絕、駕駛下馬、死亡與斷線。
- 騎姿與攝影機高度、Shift 速度、E 下馬、傳送與場景切換。
- 放置兩匹後存檔、退出與讀檔；另一個存檔、新遊戲、備份回復。
- Application Control 是否允許遊戲載入最新版 DLL。

碰撞仍以駕駛膠囊為主，馬頭尾可能穿插物件；程序步態在斜坡可能滑步。
預覽僅驗證模型與步態，不能替代 Unity 材質、角色坐姿或多人實測。
