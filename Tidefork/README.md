# 叉潮像 / Tidefork Idol — 0.16.3

商人新增 **叉潮封印球**，物品 ID `47940`，固定 **1 金／1 顆**。購買數量沿用原生 `maxStack = 1`，背包容量仍由既有 ItemStacks 處理。

## 使用

在背包使用／右鍵使用召喚球，向角色面向的前方約 5 m 拋出；該點不合適時依序改試 4、3、6 m。飛行 0.65 秒，落地後 1.5 秒展開叉潮像；完成出場才開始索敵。這版是背包使用觸發的投擲，不是可裝備到手上的瞄準武器。

落點需有 NavMesh、低於 35 度的地面、約 2.3 m（門高）淨空及無障礙投擲軌跡；落點不合法或生成失敗時不扣道具。每次成功只扣 1 顆。使用間隔至少 1 秒。

所有玩家（含房主）需使用支援本協定的 mod。房主會確認連線成員完成握手；有玩家正在載入房間時暫不允許召喚。此限制避免其他玩家只看到原生蜘蛛而沒有自製模型。

攻擊預告使用薄線輪廓；出手有水弧、水環和水珠，受擊有短暫震動。傷害由房主範圍與遮擋檢查決定，再經原生 `PlayerNet.HitClientRpc` 傷害路徑處理；保留原生格擋、無敵與客戶端距離複核。每招每位玩家只判定一次。樓層高度差與障礙物會擋住傷害。傳給 `HitClientRpc` 的距離上限涵蓋整個判定範圍（含 1.8 m 高度差；高度容許不隨範圍加倍，避免打穿樓層），避免被原生客戶端 3D 距離複核誤擋。

0.16.2 起 HP 1000、移除上限與時間限制；0.16.3 移動再 +50%（索敵除外）、重新尋路 0.15 s、前搖恢復原值、突咬 6 m／橫掃 3.5 m／震波 6 m。所有平衡數值集中在 `TideRules.cs`。音效沿用既有遊戲回饋，此版没有加入新音效資產。

## 模型與網路實作

- 依照片與概念圖製作的低面數模型：8 個關節、64 mesh parts、1,744 triangles（執行時依關節＋材質合併成少量 mesh，減少 renderer 數）；青銅、暗紅胸板、金色孔眼、青色發光縫。`Assets/model-preview.png` 是實際 JSON 幾何的離線預覽，不是遊戲截圖。
- `tools/build-model.js` 產生 `Assets/model.json`；使用實際同份資產在 Unity 建立 Mesh。`tools/preview-model.py` 以 Pillow／NumPy 深度光柵化三視角。
- 以 `SpawnManager.ManualSpawn(Spider, ...)` 取得原生已註冊的 NetworkObject、NetworkTransform、Vulnerable、Interactive、NavMeshAgent。已確認 `SpiderMelee(107)` 根節點含上述元件。
- 新增的模組皆為普通 MonoBehaviour，不改動原生 NetworkBehaviour／RPC 排序。對有 TideCreature 標記的個體抑制原生 AI、動畫攻擊與死亡掉落，正常野生蜘蛛維持原邏輯。原生 Animator 保持啟用（NetworkAnimator 每幀讀取、無 enabled 防護），只強制關閉蜘蛛 renderer；名稱／血條改到模型上方 3.2 m。
- 房主控制移動與戰鬥。`Tony.Tidefork.v1` 在動作切換時立即傳送動作時間與 ID 清單，另每 0.5 秒心跳（動作變化最多每秒 10 次）；快照每 12 隻分一包（v2 協定），怪物再多也不會超過傳輸層單包上限；客戶端只接受房主清單，等待原生實體到達後掛上模型，支援晚加入。使用原生 NetworkTransform 同步位置。
- 離房、讀檔、新遊戲、換 active scene 時清除。出場不接受傷害，死亡不再攻擊。單機暫停時保留攻擊前搖與生命週期。
