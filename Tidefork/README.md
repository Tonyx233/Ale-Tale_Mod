# 十魚架 — 0.17.0

以天野裕夫的雕塑《十魚架》（平成元年 3 月）為原型的召喚怪物。程式內部名稱仍為 Tidefork（`Tidefork/`、`Tony.Tidefork.v3`）。

商人新增 **十魚架球**，物品 ID `47940`，固定 **1 金／1 顆**。商店描述為三行「十魚架／天野 裕夫／平成元年3月」，所有語言相同；怪物頭上名稱為「十魚架」。購買數量沿用原生 `maxStack = 1`，背包容量仍由既有 ItemStacks 處理。

## 使用

在背包使用／右鍵使用召喚球，向角色面向的前方約 5 m 拋出；該點不合適時依序改試 4、3、6 m。飛行 0.65 秒，落地後 1.5 秒展開十魚架；完成出場才開始索敵。這版是背包使用觸發的投擲，不是可裝備到手上的瞄準武器。

落點需有 NavMesh、低於 35 度的地面、約 2.3 m（門高）淨空及無障礙投擲軌跡；落點不合法或生成失敗時不扣道具。每次成功只扣 1 顆。使用間隔至少 1 秒。

所有玩家（含房主）需使用支援本協定的 mod。房主會確認連線成員完成握手；有玩家正在載入房間時暫不允許召喚。此限制避免其他玩家只看到原生蜘蛛而沒有自製模型。

## 行為與數值

攻擊預告使用薄線輪廓；出手有水弧、水環和水珠，受擊有短暫震動。傷害由房主範圍與遮擋檢查決定，再經原生 `PlayerNet.HitClientRpc` 傷害路徑處理；保留原生格擋、無敵與客戶端距離複核。每招每位玩家只判定一次。樓層高度差與障礙物會擋住傷害。傳給 `HitClientRpc` 的距離上限涵蓋整個判定範圍（含 1.8 m 高度差；高度容許不隨範圍加倍，避免打穿樓層），避免被原生客戶端 3D 距離複核誤擋。

潮彈（0.17.0）：蓄力時頭冠上方聚出一顆水球，落點地面同時出現外圈（2.5 m）與逐漸擴大的內圈，內圈碰到外圈的瞬間就是落地時間。水球沿拋物線飛行並拖出水痕，落地爆出水環與水花。弧線依序試 3、2、1.2 m 高，取第一條不被牆、天花板擋住的（玩家與怪物不擋）；頭頂正上方有天花板、或三種弧線都被擋時不出招。落點預判落在懸崖外或牆後時改瞄目標腳下。落地時由房主判定 2.2 m 圈內、高度差 1.8 m 內且與落點之間無遮擋的玩家，經原生 `HitClientRpc`（從天而降，**不能格擋**）扣血，再經原生 `HitEffectClientRpc` 施加緩速；兩者都保留原生無敵與客戶端距離複核。緩速是原生效果，重複命中會取代而不是疊加。十魚架死亡時空中的水彈一併消失、不造成傷害。

0.16.2 起 HP 1000、移除上限與時間限制；0.16.3 移動再 +50%（索敵除外）、重新尋路 0.15 s、前搖恢復原值、突咬 6 m／橫掃 3.5 m／震波 6 m；0.17.0 新增潮彈。所有平衡數值集中在 `TideRules.cs`。音效沿用既有遊戲回饋，此版没有加入新音效資產。

## 模型與網路實作

- 依照片與概念圖製作的低面數模型：8 個關節、64 mesh parts、1,744 triangles（執行時依關節＋材質合併成少量 mesh，減少 renderer 數）；青銅、暗紅胸板、金色孔眼、青色發光縫。`Assets/model-preview.png` 是實際 JSON 幾何的離線預覽，不是遊戲截圖。
- `tools/build-model.js` 產生 `Assets/model.json`；使用實際同份資產在 Unity 建立 Mesh。`tools/preview-model.py` 以 Pillow／NumPy 深度光柵化三視角。
- 以 `SpawnManager.ManualSpawn(Spider, ...)` 取得原生已註冊的 NetworkObject、NetworkTransform、Vulnerable、Interactive、NavMeshAgent。已確認 `SpiderMelee(107)` 根節點含上述元件。
- 新增的模組皆為普通 MonoBehaviour，不改動原生 NetworkBehaviour／RPC 排序。對有 TideCreature 標記的個體抑制原生 AI、動畫攻擊與死亡掉落，正常野生蜘蛛維持原邏輯。原生 Animator 保持啟用（NetworkAnimator 每幀讀取、無 enabled 防護），只強制關閉蜘蛛 renderer；名稱／血條改到模型上方 3.2 m。
- 房主控制移動與戰鬥。`Tony.Tidefork.v3` 在動作切換時立即傳送動作時間與 ID 清單，另每 0.5 秒心跳（動作變化最多每秒 10 次）；客戶端只接受房主清單，等待原生實體到達後掛上模型，支援晚加入。使用原生 NetworkTransform 同步位置。
- 潮彈不產生任何網路物件、也不另外傳訊息：房主在蓄力開始時就定好擲出時間、飛行時間、弧高、起點與落點，寫進該隻的快照；各端依 ServerTime 自行畫出蓄力、飛行與落地，晚加入也能接上空中的水彈。每隻同時最多一顆（最長 0.7＋1.63＋0.6 s 特效 < 5 s 冷卻）。
- 快照每 **5 隻**分一包（v3 協定；v2 為 12 隻）：NGO 的字串以 UTF-16 傳送（每字 2 bytes），加入潮彈欄位後 12 隻會超過 LAN／Relay 用的 `UnityTransport` 單包上限 6144 bytes。`run-tidefork.ps1` 依 Record 欄位計算最壞情況（場景名上限 32 字；遊戲場景名最長 10 字）：每包 5,522／6,144 bytes。v3 與舊版不相容，所有玩家需同版本。
- 離房、讀檔、新遊戲、換 active scene 時清除。出場不接受傷害，死亡不再攻擊（含空中水彈）。單機暫停時保留攻擊前搖、空中水彈、冷卻與生命週期。

## 驗證與限制

- `tests/run-tidefork.ps1`：103,342 個購買／權限／範圍（含原生距離複核覆蓋）／攻擊時序／潮彈規則、3,968 個幾何檢查、92 個遊戲 API／權限／打包／協定檢查（含原生緩速「取代不疊加、降低移動速度」的 IL 檢查與快照單包大小上限）。
- 實際 `Assembly-CSharp.dll` 已核對所有 Harmony target、原生生成、武器命中、傷害與狀態效果 RPC。原生 prefab 資產亦已唯讀檢查。
- 完整 build 含原本 M4、點唱機、雙馬、堆疊等模組；M4、ItemStacks、QuickStack、Horse API 回歸通過。
- 0.16.x 已由 Tony 單人遊戲內實測。**潮彈（0.17.0）尚未遊戲內驗收**：蓄力／弧線／預告圈的實際外觀、室內天花板下的弧高選擇、落地命中與緩速手感都還沒在 Unity 裡看過。
- 待遊戲驗收：潮彈命中與緩速（房主與客戶端都要被打到一次）、射完繼續追、目標站在走不到的地方時會出手、死亡時空中水彈消失；雙人同步、晚加入、大量怪物時的效能與分包同步。
