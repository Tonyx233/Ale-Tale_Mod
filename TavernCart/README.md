# 單人小車（整合版 0.3.0）

第一人稱、街機式單人載具，木製車體與四輪直接由程式產生，無外部模型依賴。
功能包含在原有 `Tony.TeammateHealthBars.dll`，與血量面板及 YouTube 點唱機一起載入。

## 操作

- 單人進入遊戲後，嘗試在玩家附近的戶外空地放一台車。
- 沒看到車時，走到戶外按 **F6** 放置／召回；騎乘中不能召回。
- 看向車、靠近約 2.8 個遊戲單位內，按 **E** 上車。
- **WASD** 沿用角色方向移動，滑鼠控制視角；**Shift** 加速。
- 按 **E** 下車；若周圍沒有安全落腳點會提示先移到空地。
- 不需要購買，不修改遊戲金幣、任務或存檔。車不持久化，重新進遊戲會重建。

## 設定

既有 `BepInEx/config/Tony.TeammateHealthBars.cfg` 新增 `[Cart]`：

| 設定 | 預設 | 說明 |
|---|---|---|
| Enabled | true | 啟用小車 |
| SummonKey | F6 | 放置／召回 |
| MountKey | E | 上下車 |
| SpeedMultiplier | 1.8 | 一般騎乘速度倍率 |
| SprintMultiplier | 2.4 | 按 Shift 的速度倍率，不低於一般騎乘 |

倍率相對於同樣方向、同樣角色效果下的步行速度，不代表固定世界速度。
遊戲目前沒有在移動方法讀取 `sprintSpeedModifier`，因此 Shift 由模組自行判斷。
設定鍵位若與其他模組衝突可自行修改；畫面提示使用預設鍵位說明。

## 邊界與清理

- 僅在房主且連線人數為 1 時可用；其他玩家加入後自動結束騎乘並移除本機車。
- 騎乘期間停用跳躍、蹲下、衝刺技能、攻擊、使用物品互動與丟棄，隱藏第一人稱手部。
- 原本 CharacterController 處理坡地與碰撞；騎乘時暫時擴大半徑。
- 移速只在原生移動方法執行期間套用，finalizer 恢復原值，不覆蓋永久角色設定。
- 下車恢復碰撞半徑及手部；死亡、傳送、離開場景與停用模組亦清理狀態。
- 進水時結束騎乘；請在乾地召回。

## 驗證與限制

已確認：針對本機遊戲 assemblies 編譯；原生方法與輸入攔截點的靜態檢查。
未完成：遊戲內生成、上下車、牆面／坡地碰撞、速度、死亡與加入玩家的實機測試。

這不是完整物理汽車：不含輪胎摩擦、懸吊、翻車、第三人稱坐姿、載貨或多人乘坐。
碰撞使用膠囊而非整台車的矩形輪廓，車體角落可能有視覺穿插。
上車後視角仍是第一人稱，WASD 可側移；本版的目標是快速交通原型。

建議實機檢查：
1. 戶外 F6 生成、E 上車、W/Shift 比步行更快。
2. 牆面、坡地及狹窄處不穿越；E 下車不進入牆內。
3. 下車後移速與工具操作恢復；開選單時不誤操作小車。
4. 死亡、讀檔、退出及第二位玩家加入後沒有殘留加速或隱藏手部。
